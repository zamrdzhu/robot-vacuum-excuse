The funniest one-line excuse a robot vacuum gives for missing a spot, written for make.fun's "The Robot Vacuum's Best Excuse" bounty: one line, 140 characters at most, in the vacuum's own voice.

## The line

> I did not miss that spot. My sensors found a crumb with diplomatic immunity, and I respectfully declined to engage.

## Run it

```sh
python3 main.py
```

The program prints exactly one line and writes the same line (no trailing newline) to `/output/entry.txt`.

## Why this line

The excuse is rooted in the vacuum's own world — its sensors doing the detecting — and the joke turns on a clean, straight-faced escalation: the crumb is not dirt, it is a diplomat, and the machine is far too polite to start an international incident over it. It lands on the first read, with a tidy turn at the end and no setup that needs explaining.
